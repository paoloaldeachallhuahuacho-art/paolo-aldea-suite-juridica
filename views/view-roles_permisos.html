Matriz de Roles y Gestión de Permisos (RBAC)

Seguridad Activa

Segregación de funciones por perfil y control granular de accesos por módulo para cada colaborador.

0 Colaboradores con Roles
Nivel 1: Dirección 0

Administrador / Socio Principal

Acceso total e irrestricto a la configuración del sistema, gestión de usuarios, todas las sedes, reportes financieros y expedientes confidenciales.

Nivel 2: Litigio 0

Abogado Asociado / Líder de Caso

Acceso de lectura y escritura a los expedientes asignados, gestión de plazos y redacción de escritos. Sin acceso a configuración global ni finanzas generales.

Nivel 3: Soporte Procesal 0

Asistente Legal / Practicante

Acceso limitado a la carga de documentos, consulta de estados de expedientes y registro de asistencias o tareas asignadas.

Nivel 4: Operaciones & Front 0

Personal Administrativo / Recepción

Gestión de control de asistencia, agenda general y recepción de clientes, sin visibilidad de detalles íntimos de litigios.
